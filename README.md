# 🌿 SkinWise – Your Personal Skincare Companion

**Understand your skin. Discover your routine. Find what works for you.**

🔗 **Live Website:** https://skinwise-mla3.onrender.com/

## About the Project

SkinWise is a personalised skincare recommendation website designed to help users understand their skin type, discover suitable skincare routines, and explore products based on their individual needs and budget.

The platform aims to make skincare simpler through an easy-to-use interface and personalised recommendations.

## ✨ Features

- **Know Your Skin:** Take a short assessment to identify your likely skin type.
- **Find Your Routine:** Discover a skincare routine based on your skin type, concerns, and sensitivity.
- **Find Your Products:** Explore skincare product recommendations based on your skin type, primary concern, and budget.
- **Product Information:** View product images, descriptions, and pricing.
- **Simple Interface:** Navigate through an elegant and user-friendly design.

## 💻 Run the Project Locally

**1. Clone the repository**

```bash
git clone https://github.com/dilpreet15857/SkinWise.git
```

**2. Navigate to the project folder**

```bash
cd SkinWise
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the Flask application**

```bash
python app.py
```

**7. Open the website**

Visit http://127.0.0.1:5000/ in your browser.
